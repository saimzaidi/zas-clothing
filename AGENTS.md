# AGENTS.md

- Read `PRD.md`, `Architecture.md`, and `progress/log.md` before writing any code. Continue from where the log stops.
- Build only what the PRD lists. If something is unclear, ask.
- Keep `progress/log.md` updated with short bullets only:
  - Before starting a piece of work, add `IN PROGRESS: <task>`.
  - When finished, change it to `DONE: <task>`.
  - Update after every small step (one page or one component group), never after a large chunk.
  - Keep a single `NEXT: <next step>` line at the bottom of the log.
- If the project is a git repo, commit after each `DONE` step.
